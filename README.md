# Artist Archive

NovelAI 작가 태그를 모아 선택·복사하고, 작가별 화풍 참고 이미지·메모·라벨을 정리하는 단일 HTML 아카이브입니다. (Mac 스타일 1.1.1 기반 순정판 · 기본 작가 태그 없음)

**바로 사용:** https://yuyeonha64-del.github.io/artist-archive/

- 작가 태그는 ‘태그 추가’로 직접 등록하거나, `작가태그__번호.png` 이름의 이미지를 끌어다 놓으면 자동으로 만들어집니다.
- 모든 자료는 사용하는 브라우저에만 저장됩니다(서버 전송 없음). 기기·브라우저를 바꾸기 전에는 ‘저장 · 백업’으로 파일 백업을 해 두세요.
- `index.html` 파일 하나만 내려받아 오프라인으로 열어도 똑같이 동작합니다.

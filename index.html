파일명에 프롬프트 전체·가중치·여러 작가 이름을 섞지 마세요. 한 파일에는 작가 태그 하나만 사용하고, 혼합 화풍은 직접 만든 별도 태그에 묶을 수 있어요. 이 도구는 그림을 보고 작가나 화풍을 추측하지 않습니다.

작가 조합 · 라벨 · 비교 · 이동

태그를 체크하고 ‘작가 조합’에서 이름을 붙여 저장하세요. ‘선택에 추가’는 현재 체크를 보존하며 ‘선택 교체’는 조합의 순서를 그대로 불러옵니다. 작가별 ‘화풍 라벨’을 저장하면 목록에서 분류별로 좁혀볼 수 있고, 라벨은 태그 복사에 포함되지 않습니다. ‘화풍 비교’에서 2~4명을 나란히 보고, 작가 패널의 ‘이미지 선택 · 다른 작가로 이동’에서 잘못 분류한 이미지를 옮길 수 있습니다. 이동은 두 작가의 저장이 함께 완료될 때 적용하며 마지막 이동을 되돌릴 수 있습니다.

새 작가 태그 추가

‘태그 추가’에서 한 줄에 하나씩 입력하세요. 쉼표로 이어진 목록은 입력 구분을 바꾸면 됩니다. 중복은 미리 표시하고, 추가한 태그도 검색·선택·즐겨찾기·이미지·메모에 사용할 수 있습니다. 최신 자료를 공유할 때는 추가 태그를 포함하는 ‘이미지 포함 HTML 저장’을 이용하세요. 기존 버전의 JSON 백업도 불러올 수 있습니다.

체크와 화풍 보기는 따로

체크박스는 복사할 태그를 담고, 작가명·썸네일은 미리보기를 엽니다. 복사 아이콘은 해당 태그 하나만 복사합니다.

이미지 등록과 되돌리기

작가별 화면의 ‘이미지 여러 장 추가’를 사용하거나 상단의 ‘이미지 등록’으로 일괄 연결하세요. 기존 이미지를 지우지 않고 추가하며, 같은 작가의 동일한 이미지는 건너뜁니다. 최근 등록은 안내 영역에서 한 번에 되돌릴 수 있어요. 되돌려도 작가 태그와 메모는 유지됩니다.

자동 분류와 파일명

전체 화면에 여러 파일을 놓으면 이름이 맞는 파일부터 바로 등록됩니다. Artgerm__01.png처럼 작가태그 뒤에 밑줄 두 개와 번호를 붙이세요. 연결이 불확실한 이미지는 확인 목록에 남습니다. 자세한 예시는 ‘이미지 파일명 안내’에서 복사할 수 있어요.

기기 저장 ≠ 파일 저장

자동 저장은 같은 브라우저에서 다시 열 때 사용합니다. 시크릿 모드·저장 공간 정리·파일 위치 변경 등의 경우 유지되지 않을 수 있습니다. 백업 파일을 별도로 보관하세요. 자동 클라우드 동기화는 없습니다.
